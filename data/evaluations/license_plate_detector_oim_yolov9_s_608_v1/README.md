# OIM YOLOv9-S-608 Plate Detector v1

This directory is the current tracked detector-decision record for license-plate
localization.

The active detector is Open Image Models YOLOv9-S-608 with uniform small-object
tiles and threshold `0.30`. Model weights are local-only and ignored by Git.

Files:

- `selected_configuration.json` records the active detector configuration and
  configuration hash.
- `selected_detector_decision.md` records the selection rationale, finalist
  metrics, calibration result, rejected alternatives, and next step.
