## Hardening Changes

- Effective privacy-region hashes are computed before and after media-aware mutations.
- No-op/idempotent effective-region changes update working state and History without starting a reviewed-media render job.
- Compatible queued/running jobs are reused when a repeated request targets the same effective-region hash.
- Materialization jobs carry target effective-region hashes and published working-state revisions.
- Stale jobs cannot publish after reset, restore, restart, or newer media-changing state.
- JSON request bodies are bounded.
- MP4 Range serving covers normal and suffix requests, and rejects invalid, multi-range, and out-of-bounds requests with `416`.

## Non-Claims

This snapshot does not claim zero privacy leaks, remote/multi-user security, identity recognition, or universal production readiness. Remote deployment still requires authentication, authorization, CSRF/origin policy, TLS, quotas, operational backup/restore, and a separate security review.
