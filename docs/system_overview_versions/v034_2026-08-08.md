## Save And Planning Changes

- Manual correction Preview writes a hash-chained preview event and token bound to case, session, source media, working-state revision, stable draft hash, and preview output.
- Save requires that token, appends `manual_correction_saved`, creates the linked verification task, adds the correction to active working state, and schedules Latest reviewed publication when effective regions change.
- Single-frame, fixed-box interval, and interpolated corrections are source-frame-keyed and participate in effective-region hashing.
- v1.5 materialization plans report exact changed source-frame intervals and counts plus job stage/progress metadata.
- Segment-level reviewed-media reuse is not enabled; the full-render fallback remains the publication path until parity is proven.
